Выполнение 'main.py' занимает примерно 2.5 часа на персональном обарудовании
В 'test.py' используется уже готовая БД
Корректность работы была проверена для операционной системы "Ubuntu 25.04" и браузера "chromium 142.0.7444.59"

*Общий вид записи для БД:
{
    'institute_name': str,          # Название института/университета
    'direction': str,               # Направление подготовки
    'form': str,                    # Форма обучения
    'program_names': List[str],     # Список названий программы
    'history': List[{
        'year': int,                        # Год
        'budget_places': int/None,          # Количество бюджетных мест
        'paid_places/contract': int/None,   # Количество платных мест/контрактов
        'passing_score_budget': int/None,   # Проходной балл на бюджет
        'passing_score_paid': int/None      # Проходной балл на платное
    }],
    'required_exams': List[str]     # Список требуемых экзаменов
}

Методы обращения к БД:
insert_record() - для добавления записей вида*
get_records() - извлечение записаей по поиску с поддержкой:
    нулевого ключа (возвращает все записи)
    поиска подстрок в текстовых полях
    поиска по спискам (хотя бы одно совпадение)
    регистронезависимого поиска
